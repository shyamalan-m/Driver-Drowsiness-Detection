# Driver Drowsiness Detection System

A real-time driver drowsiness detection system developed using Python, OpenCV, Dlib, and computer vision techniques.

## Overview

Driver fatigue can reduce alertness and increase the risk of accidents. This project uses facial landmark detection and eye-state analysis to monitor the driver's alertness and identify signs of drowsiness.

When drowsiness is detected, the system provides an automated alarm to alert the driver.

## Technologies Used

* Python
* OpenCV
* Dlib
* Computer Vision

## Key Features

* Real-time driver monitoring
* Facial landmark detection
* Eye-state analysis
* Drowsiness detection
* Automated alarm alert
* Continuous monitoring

## How It Works

1. Captures video from the camera.
2. Detects the driver's face.
3. Identifies facial landmarks.
4. Analyzes the eye state.
5. Detects signs of drowsiness.
6. Activates an alarm when drowsiness is detected.

## Project Structure

The repository contains the Python source files, required resources, and supporting files used to run the drowsiness detection system.
